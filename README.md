# MacroLoom

Windows 用の汎用キーマクロアプリです。Ultima Online (2D クライアント) での利用を想定して作り始めましたが、どのゲーム・アプリでも使えます。
ゲームのメモリや通信には一切触れず、キー/マウス入力の送信と、画面の色・ログファイルの読み取りだけで動きます。

> **注意**: UO 公式サーバーでは、承認されていない外部ツールや放置マクロは規約違反になり得ます。使う前に必ず規約を確認し、その場で操作している前提で使ってください。

## できること

- **アプリ別プロファイル** — 対象の exe 名（例: `client.exe`）が前面のときだけマクロが有効
- **起動キー** — キーボード（Ctrl / Shift / Alt 組み合わせ可）、マウスの中ボタン・サイドボタン・ホイール
- **動作モード** — 1回実行 / 押している間くり返す / 押すたびに開始・停止
- **手順** — キーを押す、文字入力、待ち（ランダム幅つき）、マウスのクリック・ダブルクリック・移動、キーの押しっぱなし
- **画面の色を見る** — 指定位置の色で条件分岐、色が変わるまで待つ（HP バーなど）
- **ログを読む** — ゲームが書き出すログに特定の文字が出たらマクロを起動、出るまで待つ
- **一時停止キー**（既定は Pause）と診断バー（最後に検知したキー・起動したマクロ・送信の成否）

## 使い方

1. `MacroLoom.exe` を起動すると、ブラウザに設定画面（`http://127.0.0.1:47811/`）が開き、タスクトレイに常駐します。
2. プロファイルの「対象アプリ」に exe 名を入れ、マクロを追加して起動キーと手順を設定します。保存は自動です。
3. 終了はトレイアイコンの右クリック →「終了」。

新しいバージョンを起動すると、動いている古いバージョンは自動で終了して置き換わります。設定画面の左上にバージョンが出ます。

設定は `%APPDATA%\MacroLoom\config.json` に保存されます。

### キーが効かないとき

- プロファイルの「キーの送り方」を切り替えて試してください（キー入力 / ウィンドウへ直接送る / Unicode 文字入力）。
- 「キー入力」では文字もキーとして送るので、ゲーム側の IME（日本語入力）はオフにしてください。
- ゲームを管理者として実行している場合は、MacroLoom も管理者として実行してください。
- 診断バーで、キーが検知されているか・マクロが起動したか・送信が成功したかを確認できます。

### UO でログを使う

ゲーム内オプションでジャーナルのファイル保存を有効にし、そのファイルのフルパスをプロファイルの「ログファイル」に指定します。設定画面に「監視中 / 最新の行」と出れば読めています。

## ビルド

Go 1.24 以上。外部ライブラリは使っていません。

```
set GOOS=windows
set GOARCH=amd64
go build -trimpath -ldflags "-H windowsgui -s -w" -o MacroLoom.exe .
```

push すると GitHub Actions が Windows 上でビルドし、`MacroLoom.exe` を Artifacts に置きます。

## 構成

| ファイル | 内容 |
|---|---|
| `main_windows.go` | フック、入力送信、マクロ実行、ログ監視、トレイ、設定画面用のローカル HTTP サーバー |
| `config.go` | 設定の型・検証、前面アプリに対する有効マクロの決定 |
| `keys.go` | キー名とコードの対応表 |
| `ui.html` | 設定画面（exe に埋め込み） |

## 既知の制限

- 64bit Windows 専用。
- 署名のない exe のため、SmartScreen やウイルス対策ソフトが警告を出すことがあります。
- ゲーム内の数値（HP の値、ターゲットなど）は読みません。読めるのは画面の色とログだけです。
- 画面の色判定はウィンドウ内の座標に依存するので、UI の配置を変えたら位置を取り直してください。
